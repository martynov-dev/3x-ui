# Состав подписки и автоматическая выдача балансировщиков

## Разделение ответственности

1. `ClientInbound` задаёт доступ аккаунта к входящим. Скрытие профиля не меняет этот доступ.
2. `SubBalancer` задаёт стратегию, участников и аудиторию составного профиля. Общий SubID означает общую подписку.
3. `hiddenMemberIds` задаёт только видимость самостоятельных JSON-профилей. Это подмножество участников балансировщика.
4. `autoJson` разрешает согласование JSON по прежней ссылке для получателей этого балансировщика. Это не отдельное право доступа.

## Путь запроса

`SUBController.subs` сохраняет существующие проверки HWID, HTML и приоритет Clash. Для приложения, совпавшего с JSON User-Agent, вызывается тот же генератор JSON, что обслуживает явный `/json/`.

Генератор сначала получает разрешённые аккаунту входящие и хосты. Затем строит все доступные балансировщики. Только успешно построенный балансировщик может включить автоматическую выдачу и скрыть выбранные самостоятельные профили. Скрытие применяется после сборки всех балансировщиков: общий участник остаётся доступным каждому из них.

Если глобальное автоопределение JSON выключено, стандартная ссылка возвращает JSON лишь при наличии успешно построенного балансировщика с `autoJson=true`. В остальных случаях сохраняется прежняя выдача ссылок/base64. Явный `/json/` сохраняет прежнее поведение. Включённое глобальное автоопределение намеренно сохраняет прежнюю область действия.

## Настройка Hysteria2 → CDN

- Разрешить выбранным аккаунтам оба входящих.
- Указать стратегию «Основной → резервный», Hysteria2 основным, CDN резервным.
- Ограничить аудиторию выбранными аккаунтами.
- Скрыть только CDN в «Скрывать отдельные профили участников».
- Включить «Выдавать автоматически по обычной ссылке» у этого балансировщика.
- Включить JSON-подписку и настроить User-Agent `(?i)incy`, но выключить глобальное автоопределение JSON.

Пользователь обновляет прежнюю подписку и выбирает составной профиль. Остальные пользователи получают прежний формат. Для получателя составного профиля весь ответ имеет формат JSON: смешанный ответ из URI и JSON не вводится.

## Совместимость и ограничения

Новые поля по умолчанию пусты/выключены. Старые балансировщики и глобальная выдача не меняются автоматически. Отключение или невозможность сборки балансировщика прекращает его влияние на формат и видимость. Обычные подписки и проверка доступа не используют `hiddenMemberIds`.

Скрываются все самостоятельные варианты хостов выбранного входящего в этой JSON-подписке. Это не запрет ручного подключения. Проверки доступности переключают новые соединения; существующие не переносятся. Полные JSON-профили используют существующие настройки маршрутизации генератора, поэтому правила приложения нужно проверять отдельно.

## Проверки

Тесты генератора покрывают скрытие одного/всех участников, прежний состав по умолчанию, отключённый/недоступный балансировщик, другую аудиторию, общих участников нескольких балансировщиков и неизменность обычных ссылок. HTTP-тесты покрывают автоматический JSON только получателям, несовместимый User-Agent, ручной режим и сохранение глобального режима. CRUD и форма проверяют сохранение настроек и запрет скрытия неучастников.
